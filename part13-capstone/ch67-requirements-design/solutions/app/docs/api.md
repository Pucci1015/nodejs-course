# API の設計

- 形は第5部からと同じ: JSON、エラーは problem+json（`errors[].pointer`）、`/api` の下
- ログインは土台の `/api/auth/…`（Cookie のセッション）。下の API は、ログインしていなければ 401
- 時刻は ISO 8601 の UTC（`2026-12-10T01:00:00.000Z`）で返す。受け取るときは、時差付きなら何でもよい（`2026-12-10T10:00:00+09:00`）
- 日付だけのもの（`?date=`）は、日本の日付

## 会議室

| メソッドとパス                                         | だれが         | 成功                                                | 失敗                          |
| ------------------------------------------------------ | -------------- | --------------------------------------------------- | ----------------------------- |
| `GET /api/rooms`                                       | ログインした人 | 200 `{ items: Room[] }`（使えるものだけ、名前の順） |                               |
| `GET /api/rooms?all=1`                                 | 管理者         | 200 停止したものも                                  | 403                           |
| `POST /api/rooms` `{ name, capacity }`                 | 管理者         | 201 + `Location`                                    | 403、422、409（名前が重なる） |
| `PATCH /api/rooms/:id` `{ name?, capacity?, active? }` | 管理者         | 200 Room                                            | 403、404、422、409            |

```json
{ "id": 1, "name": "会議室A", "capacity": 6, "active": true }
```

## 予約

| メソッドとパス                                             | だれが         | 成功                                                                         | 失敗                                              |
| ---------------------------------------------------------- | -------------- | ---------------------------------------------------------------------------- | ------------------------------------------------- |
| `GET /api/bookings?date=YYYY-MM-DD`                        | ログインした人 | 200 `{ items: Booking[] }`（その日の全部の会議室。取り消したものは出さない） | 400（日付が無い・正しくない）                     |
| `GET /api/bookings/mine`                                   | ログインした人 | 200 これからの自分の予約（早い順）                                           |                                                   |
| `POST /api/bookings` `{ roomId, title, startsAt, endsAt }` | ログインした人 | 201 + `Location`                                                             | 422（R1〜R5）、404（会議室が無い）、409（R6〜R8） |
| `DELETE /api/bookings/:id`                                 | 本人か管理者   | 204                                                                          | 403、404、409（始まった・取り消した）             |

```json
{
  "id": 7,
  "roomId": 1,
  "title": "定例",
  "startsAt": "2026-12-10T01:00:00.000Z",
  "endsAt": "2026-12-10T02:00:00.000Z",
  "mine": true
}
```

- `mine` は「ログインしている人の予約か」。予約した人の id やメールアドレスは返さない（要件 5節の個人情報）
- 一覧は、取り消したものを返さない。`DELETE` の後に同じ id を `DELETE` すると 409
