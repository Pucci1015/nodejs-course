# src/domain — 予約の決まり（第67章）

時刻の計算と、予約の確かめを、純粋な関数（引数だけで結果が決まり、外に何もしない関数）で書きます。「今」も引数で受け取るので、テストで時刻を自由に決められます（第56章 3節）。データベースの制約（`migrations/002_rooms_bookings.sql`）は、ここで確かめたものが、2人同時でも壊れないための最後の守りです。

| ファイル・フォルダ                   | 中身                                                                                                                                   |
| ------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------- |
| [time.ts](time.ts)                   | 日本の時刻（Asia/Tokyo）と UTC の行き来。`tokyoParts`・`tokyoDateTime`・`addDays`・`dayRange`。日本は夏時間が無いので、いつも +09:00   |
| [booking-rules.ts](booking-rules.ts) | 予約の決まりの数（`RULES`）と、時刻を確かめる `checkBookingTime`（30 分の区切り・8:00〜21:00・30 分〜3 時間・過去は不可・60 日先まで） |
| [slots.ts](slots.ts)                 | 1日の枠（8:00〜21:00 を 30 分ずつ）を作る `slotsOfDay` と、予約で埋まった枠を調べる `markBusy`                                         |
