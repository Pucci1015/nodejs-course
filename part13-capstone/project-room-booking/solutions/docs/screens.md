# 画面の設計

土台のページ（ログイン・登録・確認・再設定）はそのまま使う。足すのは4つ。

| URL            | 名前         | だれが         | 中身                                                                                               |
| -------------- | ------------ | -------------- | -------------------------------------------------------------------------------------------------- |
| `/`            | その日の予約 | ログインした人 | 日付の選択（前の日・次の日・今日）と、会議室 × 30 分の枠の表。空いている枠を押すと予約のダイアログ |
| `/mine`        | 自分の予約   | ログインした人 | これからの自分の予約の一覧と「取り消す」                                                           |
| `/admin/rooms` | 会議室の管理 | 管理者         | 会議室の一覧（停止したものも）、追加のフォーム、名前・定員・使えるかの変更                         |
| （ダイアログ） | 予約する     | ログインした人 | 会議室・日付・始まりは押した枠で決まる。題名と長さ（30 分〜3 時間）を選んで「予約する」            |

## `/` その日の予約

```
┌──────────────────────────────────────────────────────┐
│ 予約  自分の予約  会議室の管理(管理者)   alice@… [ログアウト] │
├──────────────────────────────────────────────────────┤
│ その日の予約                                            │
│ [← 前の日] 2026-12-10（木） [次の日 →] [今日]             │
│                                                        │
│ 時刻   │ 会議室A（6人） │ 会議室B（4人） │ 会議室C（12人） │
│ 08:00 │ [空き]         │ [空き]         │ [空き]          │
│ 10:00 │ 定例（自分）    │ [空き]         │ 1on1            │
│ 10:30 │   〃           │ [空き]         │   〃            │
│  …    │                │                │                 │
└──────────────────────────────────────────────────────┘
```

- 日付は URL（`/?date=2026-12-10`）に持つ。リンクを送れば、同じ日が開く（第44章 4節）
- 空いている枠はボタン。名前は「会議室A 10:00 から予約」（スクリーンリーダーで分かるように。第45章）
- 過ぎた枠はボタンにしない
- 予約の行は、題名と、自分のものなら「（自分）」。ほかの人のメールアドレスは出さない
- ほかの人が予約・取り消したら、SSE の知らせで表を読み直す

## `/mine` 自分の予約

- 早い順。「12/10（木）10:00〜11:00 会議室A 定例 [取り消す]」
- 取り消す前に確かめのダイアログ（第45章 6節の `<dialog>`）

## `/admin/rooms` 会議室の管理

- 管理者でなければ「このページは管理者だけが使えます」（API も 403 を返す）
- 一覧の各行に、名前・定員の入力と「使える」のチェック、「保存」
- 下に「会議室を足す」のフォーム（名前・定員）

## 知らせ（`role="status"`）

| できごと        | 文                                                         |
| --------------- | ---------------------------------------------------------- |
| 予約した        | 「会議室A 10:00〜11:00 を予約しました」                    |
| 重なった（409） | ダイアログの中に「その時間は、ほかの予約と重なっています」 |
| 取り消した      | 「予約を取り消しました」                                   |
