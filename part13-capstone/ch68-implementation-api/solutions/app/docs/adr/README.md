# docs/adr — 設計の決定の記録（ADR）

大きな決定を1つ1ファイルで残します。「なぜそうしたか」を、後から来た人（未来の自分）が読めるように。決定を変えるときは、ファイルを書き換えず、新しい番号のファイルを足して「0001 を置き換える」と書きます。
