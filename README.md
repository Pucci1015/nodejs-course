# Node.js で Web アプリを作るための教材

HTML・CSS・JavaScript の基本と Flask での開発経験がある人が、**Node.js で Web アプリを設計・実装・テスト・公開できる**ようになるための教材です。Mac（Apple Silicon）での開発を前提にしています。

「Web の仕組み → 素の Node.js → フレームワーク → TypeScript / React → 本番運用」の順に、下の層から積み上げます。フレームワークが隠している仕組みを自分の言葉で説明できること、ツールが変わっても使える知識を身につけることを重視しています。

## 教材の使い方

- 各部は `partNN-...` のフォルダ、各章は `chNN-...` のフォルダです。各章のフォルダには、本文（`README.md`）、サンプル（`samples/`）、練習問題（`exercises/`）、模範解答（`solutions/`）があります。
- 本文中の `$` で始まる行は、ターミナルに入力するコマンドです。読むだけでなく、必ず自分で実行してください。
- 練習問題は自分で解いてから模範解答を見てください。

### 作業用のフォルダについて

この教材のフォルダ（`~/Documents/nodejs-course`）は、見本として書き換えずに残しておきます。`npm install` を実行するプロジェクト、Git の練習用リポジトリ、本文の「手を動かす」で作るファイルは、すべて **`~/dev/`** の下に作ってください。第5部からは、各部の最初に `setup-partNN.sh` で、その部のフォルダを `~/dev/partNN` にコピーしてから使います。練習問題のスクリプトも、既定で `~/dev/` の下に作るようになっています。
