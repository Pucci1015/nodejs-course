### 問題8 環境変数を読むスクリプト

本文10.1節の `greet.sh` を広げて、環境変数 `PORT` を読む `port.sh` を書いてください。

要件:

- `PORT` があれば「`ポート 8080 で待ち受けます`」のように表示する。無ければ `3000` を使う。
- `PORT` が数字だけでできていなければ、「`PORT は数字にしてください: abc`」を **stderr** に出し、終了ステータス **1** で終わる。

確かめ方と、期待する出力:

```sh
$ bash port.sh
ポート 3000 で待ち受けます
$ PORT=8080 bash port.sh
ポート 8080 で待ち受けます
$ PORT=abc bash port.sh; echo "exit=$?"
PORT は数字にしてください: abc
exit=1
$ PORT=9000                          # export していない
$ bash port.sh                       # 何が表示されるか、予想してから確かめる
$ export PORT
$ bash port.sh
$ unset PORT
```

ヒント: 「数字だけでできていない」は、`tr -d '0-9'` で数字を消した結果が空でないか（`-n`。本文9.3節）で調べられます。`tr` に `0-9` と書くと、0〜9 のすべての数字の意味になります。

最後に、自分の PATH にフォルダがいくつ入っているかを、1行のコマンドで数えてください（本文10.2節の `tr` の例に、パイプを1段足します）。

### 問題9 エイリアスと関数を作る

`~/.zshrc` に設定を足します。書き換える前に、本文11.2節のとおりバックアップを取ってください。

1. 本文11.2節の `ll` と、11.3節の `mkcd` が足してあることを `type` で確かめてください（無ければ足します）。
2. `bak ファイル名` で、そのファイルを `ファイル名.YYYY-MM-DD.bak`（例: `memo.txt.2026-11-07.bak`）という名前でコピーする関数 `bak` を作ってください。
   - 日付は、本文5.3節のコマンド置換と `date` で作ります。
   - 引数が無いときは「`使い方: bak ファイル`」を stderr に出し、`return 1` で終わります（本文9.3節の `$#` と `[[ ]]`、11.3節の `return`）。
   - 確かめ方: `cd ~/dev/ch01/playground && bak memo.txt && ls memo.txt.*`、`bak; echo $?`（`1`）
3. `mkcd` と同じ中身を `~/dev/ch01/mkcd.sh` というスクリプトにして `bash mkcd.sh x/y` で動かすと、フォルダは作られるのに、移動はしません。なぜでしょう。

## 発展

### 問題10 ログを要約するコマンドを作る

アクセスログを要約するスクリプト `log-summary.sh` を `~/dev/ch01` に書き、どのフォルダからでも `log-summary` で動くようにします。

```sh
$ log-summary samples/access.log
ファイル: samples/access.log
リクエスト数: 80
4xx の件数: 17
5xx の件数: 7
アクセスの多いパス（上位3件）:
  18 /tasks
  12 /static/app.js
  11 /
警告: 5xx が 7 件あります
```

要件:

- 1つ目の引数でログファイルを受け取る。
- 引数が無いとき、またはファイルが無いときは、使い方を **stderr** に出して、終了ステータス **1** で終わる（本文9.3節の `count.sh` と同じ形）。
- 5xx が1件でもあれば、最後の警告を **stderr** に出して、終了ステータス **2** で終わる。無ければ **0**。
- 完成したら、本文11.4節と同じ手順で `~/.local/bin/log-summary`（拡張子なし）として置く。

ヒント: 件数は、問題5の書き方の最後に `wc -l | tr -d ' '` を付けて、`$(…)` で変数に入れます。数の比べ方は本文9.3節の表です。件数の前の空白の数は、上の例と違っていてもかまいません。

確かめ方:

```sh
$ log-summary samples/access.log; echo "exit=$?"              # 警告が出て exit=2
$ log-summary samples/access.log 2> /dev/null; echo "exit=$?"  # 警告は表示されない（stderr に出しているため）
$ log-summary nothing.log; echo "exit=$?"                      # exit=1
$ log-summary; echo "exit=$?"                                  # exit=1
$ awk '$9 < 500' samples/access.log > ok.log                   # 5xx を除いたログを作る
$ log-summary ok.log > /dev/null; echo "exit=$?"               # exit=0
```

### 問題11 リダイレクトと awk をもう一歩

1. 次の2つの結果は違います。どう違うかを確かめ、本文5.2節の「`2>&1` は、その時点の1番の行き先にそろえる」「左から順に処理される」を使って、理由を説明してください。
   ```sh
   $ bash samples/streams-demo.sh > both.txt 2>&1
   $ bash samples/streams-demo.sh 2>&1 > both.txt
   ```
2. 1 の理由を使って、`streams-demo.sh` の **stderr だけ**をパイプで `wc -l` に渡し、stdout は捨てるコマンドを書いてください（画面には `1` だけが出ます）。
3. `access.log` の応答のバイト数（10列目）の合計と平均を、1回の `awk` で「`合計: 373903 平均: 4673.79`」の形に表示してください（本文6.4節。`print` に `"文字"` と値を `,` で並べられます）。
4. 時（9時台、10時台、…）ごとのリクエスト数を表示してください（本文6.2節の `cut -d:`）。
5. ステータスコードが 500 以上のリクエストについて、IP アドレスとパスを表示してください。
