## 発展

### 問題10 ログを要約するコマンドを作る

アクセスログを要約するスクリプト `log-summary.sh` を作り、どのフォルダからでも `log-summary` で動くようにします。

```sh
$ log-summary access.log
ファイル: access.log
リクエスト数: 80
4xx の件数: 17
5xx の件数: 7
アクセスの多いパス（上位3件）:
  18 /tasks
  12 /static/app.js
  11 /
警告: 5xx が 7 件あります
```

要件:

- 1つ目の引数でログファイルを受け取る。
- 引数が無いとき、またはファイルが無いときは、使い方を **stderr** に出して、終了ステータス **1** で終わる。
- 5xx が1件でもあれば、最後の警告を **stderr** に出して、終了ステータス **2** で終わる。無ければ終了ステータス **0**。
- 完成したら `~/.local/bin/log-summary`（拡張子なし）として置き、実行権限を付け、どのフォルダからでも `log-summary` で動くようにする。PATH の設定を、どのファイルに書くべきかも答える。

ヒント: 件数は、問題5の書き方の最後に `wc -l` を付ければ数えられます。`$(…)` で変数に入れると、`echo` で表示できます。件数の前の空白の数は、上の例と違っていてもかまいません。

確かめ方:

```sh
$ log-summary ../samples/access.log; echo "exit=$?"              # 警告が出て exit=2
$ log-summary ../samples/access.log 2> /dev/null; echo "exit=$?"  # 警告は表示されない（stderr に出しているため）
$ log-summary nothing.log; echo "exit=$?"                         # exit=1
$ log-summary; echo "exit=$?"                                     # exit=1
```

### 問題11 リダイレクトと awk をもう一歩

`../samples` で行ってください。

1. 次の2つの結果は違います。どう違うかを確かめ、本文5.2節の「`2>&1` は、その時点の1番の行き先にコピーする」を使って、理由を説明してください。
   ```sh
   $ bash streams-demo.sh > both.txt 2>&1
   $ bash streams-demo.sh 2>&1 > both.txt
   ```
2. 1 の理由を使って、`streams-demo.sh` の **stderr だけ**をパイプで `wc -l` に渡し、stdout は捨ててください（画面には `1` だけが出ます）。
3. `access.log` の応答のバイト数（10列目）の合計と平均を表示してください（本文6.4節）。
4. 時（9時台、10時台、…）ごとのリクエスト数を表示してください（本文6.4節の `cut`）。
5. ステータスコードが 500 以上のリクエストについて、IP アドレスとパスを表示してください。
