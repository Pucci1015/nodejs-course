# src/lib — Express に頼らない部品

どれも、前の章の練習問題の模範解答のコピーです。第7部で `.ts` にしました（`cursor.ts` は、署名を確かめた後の中身を Zod で確かめるようにし、`event-hub.ts` は、ハンドラに `closeAll`・`size` を `Object.assign` で足して型を付けました）。Express の `req`・`res` を受け取らないので、ほかのフレームワーク（第28章）でも、そのまま使えます。
