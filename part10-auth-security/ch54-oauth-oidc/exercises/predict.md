## (3) PKCE と client_secret

このアプリは `client_secret` を持っているので、盗まれたコードを攻撃者が `token_endpoint` に送っても、`client_secret` が無ければ断られます。それでも PKCE を使う理由を、次の2つの場面で考えてください。

- `client_secret` を持てないアプリ（スマートフォンのアプリ、ブラウザだけの SPA）
- `client_secret` を持っているアプリで、攻撃者が「盗んだコードを、自分のブラウザから、そのアプリの `/auth/callback` に送り込む」とき
