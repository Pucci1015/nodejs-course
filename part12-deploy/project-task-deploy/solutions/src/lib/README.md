# src/lib — Express に頼らない部品

どれも、前の章の練習問題の模範解答のコピーです。第7部で `.ts` にしました（`cursor.ts` は、署名を確かめた後の中身を Zod で確かめるようにし、`event-hub.ts` は、ハンドラに `closeAll`・`size` を `Object.assign` で足して型を付けました）。Express の `req`・`res` を受け取らないので、ほかのフレームワーク（第28章）でも、そのまま使えます。

| ------------------------------------ | ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [cursor.ts](cursor.ts)               | 第25章 練習問題7 | `encodeCursor`・`decodeCursor`。カーソルを作る・読む。**第6部で、並べ替えと切り出し（`paginate`）を SQL に任せ、作る・読むだけを残した**                                                                                                                                                                  |
| [signed.ts](signed.ts)               | 第22章 練習問題6 | `signJson`・`unsignJson`。カーソルを作り変えられないようにする                                                                                                                                                                                                                                            |

| [sse-format.ts](sse-format.ts)       | 第27章 練習問題5 | `formatEvent` など。SSE のイベントを書く                                                                                                                                                                                                                                                                  |
| [event-hub.ts](event-hub.ts)         | 第27章 練習問題6 | `createEventHub`・`sseRoute`。**止めるときに閉じる `closeAll` を足した**（`sseRoute` だけは Express のハンドラ）。**第10部で、人ごとのハブ `createUserHubs` を足し、`sseRoute` に「リクエストからハブを選ぶ関数」も渡せるようにした。`closeAll` は、書き終わったら接続も閉じる**（成果物の README 3.6節） |
