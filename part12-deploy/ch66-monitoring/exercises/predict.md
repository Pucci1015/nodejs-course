# 第66章 練習問題4: 考えて答える

本文を見ながら、答えを書いてください。答えは [../solutions/README.md](../solutions/README.md) の問題4にあります。

1. ある API の、かかった時間の平均は 100ms、p99 は 2 秒でした。1 日に 100 万回呼ばれるとすると、2 秒以上待った頼みは、だいたい何回ありますか。知らせる（アラート）条件は、平均と p99 のどちらで決めますか（1.2節、4.1節）。

2. メトリクスのラベルを、`route` の代わりに `req.originalUrl`（`/api/tasks/123?sort=dueDate` のような、頼まれた URL そのもの）にしました。数か月動かすと、何が起きますか（3.3節）。

3. 4.3節で `/cpu` に負荷をかけている間、`/fast` の p50 は 179.2ms でした。でも、`app.ts` のログの `/fast` の `ms` は、ほとんど 0〜2 でした。どちらが正しいのですか。なぜ違うのですか（4.3節）。

4. `/cpu` に、同時 10 本ではなく **同時 1 本**で負荷をかけると、毎秒の回数と p50 は、同時 10 本のとき（毎秒 35 回、p50 233.9ms）と比べてどうなると思いますか。予想してから試してください。

   ```sh
   $ node samples/load.ts http://127.0.0.1:9867/cpu 1 5
   ```

5. 第4部 第22章の `SessionStore`（メモリ）でログインを覚えるアプリを、ロードバランサの後ろで 2 台にしました。利用者がログインした直後に、何が起きますか（7.3節）。

6. アプリの `/healthz` は、データベースが止まっていても 200 を返します。ロードバランサがこの `/healthz` で台を選んでいると、データベースが止まった台があったとき、何が起きますか。どうすればよいですか（7.1節、第60章 8節）。
