# 練習問題6 で動かすプログラム

[../supervise.test.ts](../supervise.test.ts) が、見張り役の子として起動する小さなプログラムです。書き換えなくてかまいません。

| ファイル | 動き |
| --- | --- |
| [exit1.ts](exit1.ts) | すぐに終了コード 1 で終わる（起動してすぐ落ちるアプリ） |
| [stay.ts](stay.ts) | SIGTERM を受け取るまで動き続け、受け取ったら終了コード 0 で終わる |
| [flaky.ts](flaky.ts) | 環境変数 `RUN_MS` ミリ秒だけ動いてから、終了コード 1 で終わる（しばらく動いてから落ちるアプリ） |
